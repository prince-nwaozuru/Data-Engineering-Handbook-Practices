# 6. Data Pipeline Maintenance

[`pipeline_ownership_and_runbooks.md`](pipeline_ownership_and_runbooks.md) is a maintenance plan for a team of four data engineers running five pipelines (profit, growth and engagement). It covers:

- primary and secondary owners for each pipeline
- a fair weekly on-call rotation, including how holidays are shared
- runbooks for the three investor-facing pipelines: inputs, SLAs, what can go wrong, and the checks to run each time
- an escalation path
